# Бортовик ЗМЗ 406 (каркас, версия 0.1)

Приложение показывает обороты, температуру ОЖ, напряжение, расход и ошибки (CHECK).
Сейчас работает демо-режим. Если подключён кабель KKL, он открывается, но
протокол обмена с ЭБУ (VS 5.6 / Микас 7.1) ещё не добавлен.

## Как получить APK (без установки программ на компьютер)

1. Зарегистрируйся на github.com (бесплатно) и нажми New repository, назови, например, zmz406board.
2. Нажми "uploading an existing file" и перетащи ВСЕ файлы и папки из этого архива
   (app, settings.gradle, build.gradle, gradle.properties, README.md), нажми Commit changes.
3. Папка .github может не перетащиться, она скрытая. Поэтому: Add file -> Create new file,
   в поле имени напиши `.github/workflows/build.yml`, вставь содержимое файла build.yml
   из архива и нажми Commit changes.
4. Открой вкладку Actions, дождись зелёной галочки (5-10 минут).
5. Открой готовый запуск, внизу в Artifacts скачай zmz406-apk, распакуй, получится app-debug.apk.
6. Скинь APK на телефон и установи (разреши установку из неизвестных источников).
7. Подключи KKL через OTG и запусти приложение.

Если сборка упадёт красным, открой запуск, скопируй текст ошибки и пришли мне.
